# Project Brief: Babylon Portfolio

## Core Goal

This project serves as a portfolio or playground to demonstrate various features, scenes, and capabilities implemented using the Babylon.js framework.

## Scope

The scope includes creating and integrating different interactive 3D scenes, potentially covering areas like:
- Basic scene setup
- Lighting and materials
- Physics integration (e.g., Havok)
- Character controllers
- Asset loading (GLB, textures)
- Post-processing effects
- User interaction (camera controls, input handling)

## Current Focus

The immediate focus is on implementing and refining specific playground scenes, such as the `player-controller` scene, which involves character movement, physics, and interaction within a pre-defined level.
